Cara deploy ke Vercel

  1. Push kode ke repository GitHub.
  2. Buka Vercel → New Project → Import Git Repository.
  3. Pilih framework: Vite (Auto-detect) atau Framework: Other (build command npm run build, output dir dist).
  4. Set environment (jika ada) lalu Deploy. Vercel akan membuild & menerbitkan otomatis.
